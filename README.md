# Tanjet Hawlader — Personal Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## GitHub / Vercel update
Extract this ZIP and upload all files directly to the existing repository root. Replace files with matching names and include the new `profile-photo.webp`. Do not upload the ZIP itself. Commit to `main`; Vercel can redeploy automatically when its GitHub integration is connected.

## Included
- Professional portrait, optimized for web
- Responsive desktop, tablet and phone layouts
- Animated TH monogram and compact sticky header
- Electric spark trail that follows touch and finger scrolling on phones
- Soft touch glow, scroll-progress rail, section reveal and active navigation
- Desktop portrait tilt, tap feedback and back-to-top control
- Dark/light theme and downloadable CV

## Contact form
The form opens the visitor's configured email application with a prepared message. It does not send or store messages on a server. Direct website submissions require a backend or form service.
